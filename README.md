# InternTrack — 就職活動管理Webアプリ

**企業情報・選考状況・応募締切・メールを一元管理するWebアプリケーション**

[**Webアプリのデモを試す**](https://interntrack-portfolio-demo.onrender.com/)

※採用担当者向けの公開デモです。架空データを使用しており、アカウント登録は不要です。無料サーバーのため、初回表示に時間がかかる場合があります。

## 1. 開発の背景・目的

就職活動では、複数企業の選考状況、応募締切、面接予定、企業からのメールなど、多くの情報を管理する必要があります。

これらを個別に管理すると情報が分散し、重要な予定や選考状況を把握しにくくなります。

そこで、就職活動に必要な情報を一つのWebアプリで管理できる「InternTrack」を個人開発しました。

## 2. 主な機能

### 企業・選考管理
- 企業情報の登録・編集・削除
- 応募状況・選考ステータスの管理
- 選考履歴・企業別メモの管理
- 次回選考予定や応募締切の確認

### ダッシュボード・カレンダー
- 直近7日間の予定表示
- 応募締切や選考進捗の可視化
- カレンダーによるスケジュール管理

### メール管理
- Gmail・OutlookとのOAuth認証によるメール連携をローカル版に実装
- 取得したメールの重複登録防止
- メールの件名・送信元などを利用した企業との自動紐付け
- Gmail・Outlook別のメール一覧表示
- 登録企業との再照合

公開デモでは実際のOAuth認証・メール取得を無効化し、架空メールを用いて一覧表示や企業との自動紐付けを体験できるようにしています。

## 4. 開発で工夫した点

### 選考情報の整合性

企業の選考履歴と現在のステータスを関連付け、履歴を変更・削除した場合にも選考状況を更新できるようにしました。

### メール管理の共通化

GmailとOutlookという異なるメールサービスから取得した情報を、共通のデータ構造で管理するようにしました。

これにより、メールサービスごとにデータ管理が分散することを防ぎ、一覧表示や企業との紐付け処理を共通化しています。

### 公開デモの安全性への配慮

採用担当者が実際に操作できるよう、公開版では架空の企業情報とメールデータを使用しています。

また、実際のOAuth認証やアカウント設定機能を無効化し、デモ専用のデータ領域を利用する構成にしています。

## 5. デモの操作方法

1. WebアプリのURLを開く。
2. ホーム画面で企業情報と選考状況を確認する。
3. 企業一覧から企業情報を閲覧・編集する。
4. カレンダーで選考予定を確認する。
5. メール画面でGmail・Outlookのサンプルメールを表示する。
6. 企業を追加してメールの再照合を試す。

※入力したデモデータは永続保存されません。実際の個人情報は入力しないでください。
